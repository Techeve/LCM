# Betriebssystem-Logos

256×256-PNGs, gerendert aus offiziellen/frei lizenzierten Vektorquellen von
Wikimedia Commons. Sie kennzeichnen ausschließlich das erkannte Betriebssystem
eines verwalteten Servers (nominative Nutzung). Marken bleiben Eigentum ihrer
jeweiligen Inhaber.

(lewing@isc.tamu.edu) und The GIMP genannt werden - hiermit erfolgt.
