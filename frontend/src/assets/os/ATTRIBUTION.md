# Betriebssystem- und Geräte-Logos

256×256-PNGs, gerendert aus offiziellen/frei lizenzierten Vektorquellen von
Wikimedia Commons (Ausnahme `raspberrypi.svg`, siehe unten). Sie kennzeichnen
ausschließlich das erkannte Betriebssystem bzw. Gerät eines verwalteten Servers
(nominative Nutzung). Marken bleiben Eigentum ihrer jeweiligen Inhaber.

| Datei | Quelle (Wikimedia Commons) | Rechte / Hinweis |
|---|---|---|
| `ubuntu.png` | `Logo-ubuntu cof-orange-hex.svg` | „Circle of Friends", Marke von Canonical Ltd. |
| `debian.png` | `Debian-OpenLogo.svg` | Debian Open Use Logo |
| `proxmox.png` | `Logo Proxmox.svg` (offizielles zweifarbiges Logo, auf die Bildmarke zugeschnitten) | Marke von Proxmox Server Solutions GmbH |
| `linux.png` | `Tux.svg` | Tux von Larry Ewing (lewing@isc.tamu.edu) und The GIMP |
| `raspberrypi.svg` | simple-icons (`icons/raspberrypi.svg`, CC0-1.0) | Marke von Raspberry Pi Ltd. |

`linux.png` (Tux): Die Nutzung ist gestattet, sofern Larry Ewing
(lewing@isc.tamu.edu) und The GIMP genannt werden - hiermit erfolgt.

`raspberrypi.svg`: Als einziges Logo ein SVG statt eines PNGs - die Bildmarke
ist ein einzelner Pfad, als Vektor bleibt sie in jeder Größe scharf. Auf
Wikimedia Commons gibt es sie nicht (eingetragene Marke, kein freies Werk);
die Pfaddaten stammen aus dem CC0-lizenzierten Satz simple-icons und sind mit
dem Markenrot #C51A4A eingefärbt. Der Rand (68,75 % der Fläche) steckt wie bei
den PNGs bereits in der Datei.
