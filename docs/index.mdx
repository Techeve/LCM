## Was ist LCM?

**LCM (Linux Centralized Management)** ist ein zentrales Management-Werkzeug für
Linux-Server: Go-Backend (Fiber v3, GORM, SQLite) und Svelte-5-Frontend in
**einem einzigen Binary**, lauffähig unter Linux, Windows und macOS - ohne
externe Abhängigkeiten auf den verwalteten Servern. Die Kommunikation läuft
ausschließlich über SSH (agentless).

<CardGrid stagger>
  <Card title="Agentless über SSH" icon="setting">
    Server werden mit Host-Key-Bestätigung angebunden; jeder bekommt einen
    dedizierten Service-User und ein eigenes Schlüsselpaar (Zero Trust).
  </Card>
  <Card title="Monitoring & Ampel" icon="approve-check">
    Pakete, Updates, Hardware und Speicher-Verlauf - Status 🟢🟡🔴 pro Server,
    inklusive CVE-getriebener Bewertung.
  </Card>
  <Card title="Sicherheit eingebaut" icon="shield">
    AES-256-GCM at-rest, TOTP-2FA, SSH-Hardening, Firewall, verschlüsselte
    Backups und lückenloses Audit-Log.
  </Card>
  <Card title="Automatisierung" icon="rocket">
    Servergruppen mit zeitgesteuerten Regeln und Grundsatz-Regeln, die bei
    jeder Verbindung durchgesetzt werden.
  </Card>
</CardGrid>
