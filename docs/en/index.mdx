## What is LCM?

**LCM (Linux Centralized Management)** is a central management tool for Linux
servers: a Go backend (Fiber v3, GORM, SQLite) and a Svelte 5 frontend in **a
single binary**, runnable on Linux, Windows and macOS - with no external
dependencies on the managed servers. All communication happens over SSH
(agentless).

<CardGrid stagger>
  <Card title="Agentless over SSH" icon="setting">
    Servers are onboarded with host-key confirmation; each gets a dedicated
    service user and its own key pair (zero trust).
  </Card>
  <Card title="Monitoring & status" icon="approve-check">
    Packages, updates, hardware and storage history - a 🟢🟡🔴 status per
    server, including CVE-driven assessment.
  </Card>
  <Card title="Security built in" icon="shield">
    AES-256-GCM at rest, TOTP 2FA, SSH hardening, firewall, encrypted backups
    and a tamper-evident audit log.
  </Card>
  <Card title="Automation" icon="rocket">
    Server groups with scheduled rules and baseline rules that are enforced on
    every connection.
  </Card>
</CardGrid>
