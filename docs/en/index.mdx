## What is LCM?

**LCM (Linux Centralized Management)** is a central management tool for Linux
servers: a Go backend (Fiber v3, GORM, SQLite) and a Lit web interface in **a
single binary**. LCM itself runs on Debian and Ubuntu or in a Docker
container. It reaches the managed servers over SSH, without installing anything
there, or through the `lcm-agent`, which connects outbound - even behind NAT.
You can manage Debian, Ubuntu, the RHEL family, openSUSE, Arch Linux and
Alpine.

<CardGrid stagger>
  <Card title="SSH or agent" icon="setting">
    Over SSH with host-key confirmation, a dedicated service user and its own
    key pair per server (zero trust). Where SSH cannot reach, the agent
    connects outbound.
  </Card>
  <Card title="Monitoring & status" icon="approve-check">
    Packages, updates, hardware and storage history - a 🟢🟡🔴 status per
    server, including CVE-driven assessment.
  </Card>
  <Card title="Security built in" icon="padlock">
    AES-256-GCM at rest, TOTP 2FA, SSH hardening, firewall, encrypted backups
    and a tamper-evident audit log.
  </Card>
  <Card title="Automation" icon="rocket">
    Server groups with scheduled rules and baseline rules that are enforced on
    every connection.
  </Card>
</CardGrid>
