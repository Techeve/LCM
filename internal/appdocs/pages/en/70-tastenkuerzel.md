# Keyboard shortcuts

The interface can be operated without a mouse. **`?`** opens the overview of
all shortcuts at any time - also via the account menu at the top right (entry
*Keyboard shortcuts*). Shortcuts apply in the signed-in interface while no input field has
focus; only Save (`Ctrl+S` or
`⌘S`) also works inside a field.

## Jump

Two keys in a row: first `G`, then the letter of the page.

| Shortcut | Target |
|---|---|
| `G` `D` | Dashboard |
| `G` `V` | Servers |
| `G` `G` | Groups |
| `G` `U` | Linux users |
| `G` `S` | Security |
| `G` `C` | Containers |
| `G` `J` | Jobs |
| `G` `E` | Settings |
| `G` `A` | My account |
| `G` `H` | Docs |

## Everywhere

| Shortcut | Effect |
|---|---|
| `Ctrl+K` / `⌘K` | Open the command palette |
| `?` | Open or close the shortcut overview |
| `/` | Jump to the search field of the page |
| `Ctrl+S` / `⌘S` | Save the form |
| `Esc` | Close dialog or menu |
| `←` `→` `↑` `↓` | Move between controls in menus and tables |
| `Tab` / `Shift+Tab` | Next / previous control |

## On the page

Commands with a shortcut of their own, such as **"Add server"** (`N`), are
triggered directly by the key. The overview (`?`) lists all shortcuts of the
open page; the same commands are in the command palette.

- `N` creates something new: server, group, Linux user, profile, channel,
  alert rule, app, repository, APT cache, CrowdSec LAPI, allowlist, custom
  action.
- `U` on the security page: bulk update (update all servers).
- `/` jumps to the search field of the page, where it has one: server list,
  jobs, packages of a server.

The first `Tab` on every page lands on "Skip to content" and skips the
navigation bar with `Enter`.
