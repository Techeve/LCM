# Tastenkürzel

Die Oberfläche lässt sich ohne Maus bedienen. **`?`** öffnet jederzeit die
Übersicht aller Kürzel - auch über die Schaltfläche `?` oben rechts in der
Leiste. Kürzel gelten, solange kein Eingabefeld den Fokus hat; nur Speichern
(`Strg+S` bzw. `⌘S`) greift auch im Feld.

## Springen

Zwei Tasten nacheinander: erst `G`, dann der Buchstabe der Seite.

| Kürzel | Ziel |
|---|---|
| `G` `D` | Dashboard |
| `G` `G` | Gruppen |
| `G` `U` | Linux-Benutzer |
| `G` `S` | Sicherheit |
| `G` `C` | Docker |
| `G` `J` | Jobs |
| `G` `E` | Einstellungen |
| `G` `A` | Mein Konto |
| `G` `H` | Doku |

## Überall

| Kürzel | Wirkung |
|---|---|
| `?` | Kürzel-Übersicht öffnen oder schließen |
| `/` | In das Suchfeld der Seite springen |
| `Strg+S` / `⌘S` | Formular speichern |
| `Esc` | Dialog oder Menü schließen |
| `←` `→` `↑` `↓` | In Menüs und Tabellen zwischen Bedienelementen wandern |
| `Tab` / `Umschalt+Tab` | Nächstes / voriges Bedienelement |

## Auf der Seite

Schaltflächen mit eigenem Kürzel tragen es als kleines Abzeichen direkt am
Namen, etwa **„+ Server hinzufügen `N`"**. Die Übersicht (`?`) listet alle
Kürzel der offenen Seite und erlaubt, die Abzeichen abzuschalten.

- `N` legt Neues an: Server, Gruppe, Linux-Benutzer, Profil, Regel, Kanal,
  Anwendung, Repository, Allowlist, Custom-Aktion.
- `U` auf der Sicherheitsseite: alle VMs aktualisieren.
- `/` springt in das Suchfeld: Dashboard, Jobs, Pakete eines Servers,
  Regelbausteine.

Das erste `Tab` auf jeder Seite trifft „Zum Inhalt springen" und überspringt
mit `Enter` die Navigationsleiste.
