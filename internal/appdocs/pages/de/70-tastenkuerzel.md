# Tastenkürzel

Die Oberfläche lässt sich ohne Maus bedienen. **`?`** öffnet jederzeit die
Übersicht aller Kürzel - auch über das Kontomenü oben rechts (Eintrag
*Tastenkürzel*). Kürzel gelten in der angemeldeten Oberfläche, solange kein
Eingabefeld den Fokus hat; nur Speichern
(`Strg+S` bzw. `⌘S`) greift auch im Feld.

## Springen

Zwei Tasten nacheinander: erst `G`, dann der Buchstabe der Seite.

| Kürzel | Ziel |
|---|---|
| `G` `D` | Dashboard |
| `G` `V` | Server |
| `G` `G` | Gruppen |
| `G` `U` | Linux-Benutzer |
| `G` `S` | Sicherheit |
| `G` `C` | Container |
| `G` `J` | Jobs |
| `G` `E` | Einstellungen |
| `G` `A` | Mein Konto |
| `G` `H` | Doku |

## Überall

| Kürzel | Wirkung |
|---|---|
| `Strg+K` / `⌘K` | Befehlspalette öffnen |
| `?` | Kürzel-Übersicht öffnen oder schließen |
| `/` | In das Suchfeld der Seite springen |
| `Strg+S` / `⌘S` | Formular speichern |
| `Esc` | Dialog oder Menü schließen |
| `←` `→` `↑` `↓` | In Menüs und Tabellen zwischen Bedienelementen wandern |
| `Tab` / `Umschalt+Tab` | Nächstes / voriges Bedienelement |

## Auf der Seite

Befehle mit eigenem Kürzel, etwa **„Server hinzufügen“** (`N`), löst die Taste
direkt aus. Die Übersicht (`?`) listet alle Kürzel der offenen Seite; dieselben
Befehle stehen in der Befehlspalette.

- `N` legt Neues an: Server, Gruppe, Linux-Benutzer, Profil, Kanal, Alarmregel,
  App, Repository, APT-Cache, CrowdSec-LAPI, Allowlist, Eigene Aktion.
- `U` auf der Sicherheitsseite: Sammel-Update (alle Server aktualisieren).
- `/` springt in das Suchfeld der Seite, sofern sie eines hat: Serverliste,
  Jobs, Pakete eines Servers.

Das erste `Tab` auf jeder Seite trifft „Zum Inhalt springen" und überspringt
mit `Enter` die Navigationsleiste.
