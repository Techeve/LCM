LCM 2.2 macht Server, die du per Agent verbindest, deutlich mächtiger: Sie bekommen eine Konsole im Browser und die SSH-Funktionen, die bisher nur SSH-Servern vorbehalten waren. Dazu kommen Verbesserungen bei Benutzerkonten und den öffentlichen Adressen.

### Das erwartet dich

- **Konsole auf Agent-Servern:** Der Agent öffnet eine Shell als root im Browser, Befehle und Ausgabe laufen durch die bestehende Verbindung zu LCM. Dafür muss kein Port am Server offen sein. Ticket, Berechtigung `servers:console`, Konsolen-Limit, Audit und Mitschnitt gelten wie bei SSH-Servern.
- **SSH-Funktionen für Agent-Server:** SSH-Härtung, Root-Login, SSH-Port, offene Ports und SSH-2FA lassen sich jetzt auch an Servern einstellen, die per Agent verbunden sind. Das geht schon mit jedem vorhandenen Agent.
- **Konten einladen:** Beim Anlegen eines LCM-Kontos vergibst du entweder selbst ein Passwort oder schickst dem Nutzer einen Aktivierungslink per E-Mail.
- **Eigene Adressen für Agent und API:** Unter Einstellungen → Allgemein trägst du für den Agent-Port und die MCP-Schnittstelle eigene öffentliche Adressen ein, etwa wenn ein Reverse-Proxy davorsteht. Der Assistent zum Hinzufügen eines Servers nutzt die Agent-Adresse.

### Das ändert sich für dich

- **Agent aktualisieren:** Die Konsole braucht den Agent aus dieser Version. Auf Servern mit einem älteren Agent zeigt LCM „Agent aktualisieren“ statt der Konsole. Die SSH-Funktionen laufen auch mit dem alten Agent.
- **Konsole am Agent abschalten:** Nach dem Update ist die Konsole am Agent standardmäßig an und öffnet eine root-Shell. Wer das nicht will, schaltet sie auf dem Server mit `lcm-agent terminal off` ab. Das gilt sofort, auch für offene Konsolen. `lcm-agent terminal status` zeigt den Stand. LCM erfährt davon nach dem nächsten Verbindungsaufbau des Agents.
- **SSH-Härtung auf Agent-Servern:** Sie bricht ab, wenn auf dem Server kein SSH-Schlüssel hinterlegt ist, sonst sperrst du dich nach dem Abschalten der Passwort-Anmeldung aus.
- **SSH-2FA auf Agent-Servern:** Es gibt keine Ausnahme für einen Benutzer, der sich ohne Einmalcode anmelden darf. LCM prüft nach dem Einrichten, dass sshd den Einmalcode wirklich verlangt, und nimmt die Einrichtung sonst zurück.
- **SSH-Port auf Agent-Servern:** LCM liest den aktuellen Port vom Server und prüft, dass der neue Port frei ist und danach wirklich lauscht.
- **Rolle beim Anlegen:** Im Dialog „Konto anlegen“ wählst du die Rolle aus einer Liste, statt Häkchen zu setzen.
